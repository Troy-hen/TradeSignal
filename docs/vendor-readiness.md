# MyTradeBox vendor activation checklist

Last reviewed: 2026-09-10

MyTradeBox is designed so optional vendors can remain disabled without breaking the core product. The current launch path is planning + AI classification + public procurement + EPC + company intelligence. Stripe, postal delivery and richer property-market intelligence can be added later.

## Current launch stack

### 1. Supabase — application, database and autonomous jobs

Supabase provides Postgres, Auth, Edge Functions, pg_cron/pg_net and the application data layer.

Cloudflare / Next.js runtime:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

Supabase Edge Functions receive their Supabase runtime credentials automatically. Do not manually copy the Cloudflare service key into Edge Function secrets.

`CRON_SECRET` is stored as a Supabase Edge Function secret and the same value is stored in Supabase Vault under the name `cron_secret` so scheduled pg_net calls can authenticate to Edge Functions.

## 2. OpenAI — AI classification, Ask MyTradeBox, RAG and Deep Research

Cloudflare / Next.js runtime:
- `OPENAI_API_KEY`
- `ASK_MYTRADEBOX_MODEL` (currently `gpt-5-mini`)
- `OPENAI_EMBEDDING_MODEL` (currently `text-embedding-3-small`)

Supabase Edge Functions:
- `OPENAI_API_KEY`
- `AI_ENRICHMENT_PROVIDER=openai`

The live planning enrichment prompt is `application_enrichment` version `v2-commercial`, so residential and commercial work are both first-class. The automatic classification cron should remain paused whenever API credit is unavailable; enabling it without credit would turn queued rows into failed attempts.

## 3. Plota — planning application data

Supabase Edge Functions:
- `PLANNING_PROVIDER=plota`
- `PLOTA_API_KEY`
- `PLOTA_MAX_PAGES_PER_RUN=1` while using a limited/demo allowance

Planning ingestion is autonomous and quota-conscious.

Published planning-contact lookup is optional and separate from ingestion. To enable it later in Cloudflare:
- `PLOTA_API_KEY`
- `CONTACT_INTELLIGENCE_PROVIDER=plota`

Only enable contact lookup on a Plota plan that explicitly includes the required contact data. MyTradeBox does not use consumer email/mobile enrichment as a homeowner marketing strategy.

## 4. UK public procurement — no paid API key required

The live market-signal architecture supports government procurement data from:
- Find a Tender
- Contracts Finder

Supabase Edge Functions:
- `MARKET_SIGNAL_PROVIDERS=find-a-tender,contracts-finder`

If the variable is absent, the Edge provider layer defaults to these two sources. `none` explicitly disables procurement ingestion.

The database queue and scheduled processor are already designed for sources that cannot be fetched directly from the Edge runtime. Procurement matching covers relevant trade packages including commercial refurbishment and fit-out/interiors.

Sell2Wales and Public Contracts Scotland remain optional adapters and should only be enabled after overlap and source-format testing.

## 5. GOV.UK Energy Performance data — domestic and non-domestic EPC intelligence

Cloudflare / Next.js runtime:
- `EPC_API_BEARER_TOKEN`

The EPC integration searches both domestic and non-domestic certificate datasets by project address/postcode and can surface recorded building use, energy mix, heating/fuel systems, heat pumps, solar PV/thermal, air conditioning, floor area, fabric and efficiency context where the certificate records it.

EPC is a qualification signal, not evidence that the owner or occupier intends to buy work. It is cached per unlocked opportunity to control external API use.

## 6. Companies House — company/developer intelligence

Cloudflare / Next.js runtime:
- `COMPANIES_HOUSE_API_KEY`

Used for genuine company/developer/business opportunities. It adds public company status, registered-office context, officers, accounts/confirmation-statement context, charges/insolvency indicators and basic registry health signals. It is not a credit score and officers are not automatically treated as sales contacts.

## 7. Resend — platform and notification email

Supabase Edge Functions:
- `RESEND_API_KEY`
- `RESEND_FROM_EMAIL`
- `RESEND_FROM_NAME=MyTradeBox`
- `RESEND_REPLY_TO` optional

Keep live email links disabled or test-only until `NEXT_PUBLIC_APP_URL` points to a real reachable deployment. Production sender/domain verification can wait until the MyTradeBox domain is ready.

## 8. QuoteLink — MyTradeBox-owned response tracking

Cloudflare / Next.js runtime:
- `QUOTE_LINK_SIGNING_SECRET`
- `NEXT_PUBLIC_APP_URL` once a real public app URL is ready

`QUOTE_LINK_SIGNING_SECRET` is generated by us; it is not a vendor API key. Production QuoteLink generation fails closed when `NEXT_PUBLIC_APP_URL` is absent so a live outbound message cannot accidentally contain a localhost URL.

## 9. Stripe — later, for paid territory activation

Cloudflare / Next.js runtime:
- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`

Use test-mode credentials for UAT. Stripe is not required to validate planning, AI, EPC, Companies House or public-procurement intelligence.

## 10. Stannp — later, for physical letters

Cloudflare / Next.js runtime:
- `POSTAL_OUTREACH_PROVIDER=stannp`
- `STANNP_API_KEY`

Until both are configured, postal send stays disabled. This is intentionally a later closed-loop outreach step rather than a core data dependency.

## 11. Property-market intelligence — deferred

`PROPERTY_INTELLIGENCE_PROVIDER` should remain `none` or unset for launch.

A TwentyCI adapter exists in the codebase but TwentyCI is not a launch dependency. Do not purchase or enable it simply because the adapter exists. If richer property/transaction/recency intelligence proves commercially valuable after UAT, evaluate a provider with suitable API documentation, pricing and commercial data rights before activating this layer.

## App URL during development

`NEXT_PUBLIC_APP_URL` can remain unset while building if no outbound QuoteLinks or notification links are being sent. Once a stable workers.dev or custom-domain URL is chosen, add the same public URL to both Cloudflare runtime configuration and Supabase Edge Function secrets.

For Cloudflare Workers Builds, `NEXT_PUBLIC_` variables used by the browser bundle must also be available to the build environment, not only to the Worker runtime. At minimum, mirror `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` into the connected Workers Build variables.

## Current activation order

1. Supabase connectivity and authentication
2. Plota planning ingestion
3. OpenAI classification / Ask MyTradeBox
4. Find a Tender + Contracts Finder market signals
5. EPC domestic/non-domestic intelligence
6. Companies House company intelligence
7. Resend once a usable public app URL and sender are ready
8. Stripe billing
9. Stannp postal outreach
10. Optional richer property-market provider only if UAT proves the value

The closed-loop QuoteLink and outcome-learning layer remains MyTradeBox-owned rather than delegated to any data vendor.
